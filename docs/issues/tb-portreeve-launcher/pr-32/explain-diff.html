The new information architecture

Fourth primary tab

Launcher appears after Overview, Ports, and Stacks. Onboarding explains that PortReeve injects current endpoint values but the project still owns its lifecycle commands.

Stack-linked master/detail

Why discovery belongs to an opaque document

Main inspects only the exact stack or contained working directory already associated with the opened document. The renderer can accept, edit, or ignore suggestions but cannot ask PortReeve to inspect an arbitrary path.

Editing is deliberately explicit

Missing file

Suggestions form a dirty, immediately saveable draft. Nothing executes until the resulting exact revision is trusted.

External change

Saving against stale bytes produces Review, Overwrite, or Cancel. PortReeve never silently replaces the changed project file.

Downgrade

Changing verified activation to command-only requires a warning and confirmation before Save and Trust.

Assigned ports

The editor stores endpoint mappings. Current port values are previewed from reduced stack facts and resolved again for each operation.

Action availability is evidence, not optimism

exact trusted revision
        + fresh stack evidence
        + shared lifecycle policy
        ↓
enabled action, disabled reason, or explicit confirmation

Fully observed stacks do not offer Start. Conflicts block Start. Partial and degraded paths require explicit consent. Stop invokes only the trusted project command; it does not turn PortReeve's listener inventory into implicit kill authority.

What happens while an attached Start is running?

Status and Stop remain available. Output is bounded and live for the application session. Normal close is blocked; termination is a separate explicit user action owned by Electron main.

Two smoke-test corrections

  1. A suggested missing-file draft was initially mistaken for an unchanged saved document, disabling Save and Trust. Missing documents now start from an empty baseline.
  2. Busy cleanup initially re-enabled controls blindly. Dynamic controls now re-render from semantic state, while retained controls restore their precise prior disabled value.
