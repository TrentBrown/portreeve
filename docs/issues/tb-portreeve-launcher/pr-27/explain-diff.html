Background

Two truths must meet just before execution

The checked-in portreeve.launcher.json says which endpoint should populate each environment variable, but deliberately contains no assigned port. SQLite owns the current generation and its host ports. The future command engine therefore needs a fresh, validated join between those two sources.

Project-owned

Commands, endpoint references, mapping names, schemes, working directory, and exact trusted launcher revision.

PortReeve-owned

Canonical stack identity, allocation generation, host ports, activation state, listeners, Docker evidence, and history.

P3 is still not a launcher. It creates shared environment and evidence services. P4 will add finite command execution and action policy.

Resolution is exact: the stack root, revision, generation, endpoint, and optional activation must agree. Observation is deliberately less absolute. A listener on port 43100 proves that something is listening; only a matching current activation and fresh provider evidence can prove PortReeve's verified ownership relation.

The successful result is cached by canonical root and exact launcher revision. The cache contains only resolved strings and endpoint facts—never commands, literal secrets, or raw output. Supplying an existing generation lets later Stop and Status preserve the address plan instead of reallocating around a command-only listener.

Evidence

A state table that does not confuse presence with provenance

stoppednone observed
partialsome observed
fully-observedall observed, ownership unproven
verifiedcurrent activation + active providers
conflictingmismatched durable ownership
uncertainevidence missing or unavailable

The daemon path combines stack status with an inventory inspection for each generation endpoint. A fresh listener with no confirmed run is valid command-only observation, not automatically a conflict. A confirmed provider that disappears or belongs to another claim is a conflict. A confirmed endpoint with no provider row is uncertain.

Degraded mode is weaker by construction. Fresh local lsof plus cached endpoint ports may report stopped, partial, or fully observed. Its source is always local; it can never report verified or conflicting ownership.
