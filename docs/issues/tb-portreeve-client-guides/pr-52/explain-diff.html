Authority and offline boundary

Live installation facts come from validated Desktop application services. Guide prose cannot execute. The renderer performs no documentation fetch, Markdown parse, HTML insertion, generic shell operation, PATH lookup, or CLI subprocess. The package attests the guide version and exact inventory counts before shipping.

Knowledge check

Which version does a guide describe?

The contract bundled with this Desktop application. A different managed or running version is shown as evidence, never substituted into the guide.

Does a missing daemon make the guide disappear?

No. Static guidance remains complete; installation panels label unavailable or stale evidence separately.

Why use a JavaScript module instead of JSON?

It imports cleanly through the checked JavaScript toolchain while remaining generated, static, inert, version-attested data.

What remains after this slice?

The README and bounded Guide bridge, followed by the final integrated packaged and offline verification slice.
